匯出與資料管理

PDF / Excel 用於閱讀與分享；JSON 才是完整備份與恢復用檔案。

資料安全

  • 紀錄預設只存在目前 iPhone 的瀏覽器資料庫。
  • GitHub Pages 只提供網頁本身，不會自動取得你的健康紀錄。
  • 換手機、清除 Safari 網站資料前，請先執行「備份資料」。
  • 建議定期把 JSON 備份存到 iCloud Drive。

iPhone 使用教學

① 加到 iPhone 主畫面
  1. 使用 Safari 開啟 GitHub Pages 網址。
  2. 點 Safari 的「分享」按鈕。
  3. 選「加入主畫面」。
  4. 按「新增」，之後可直接從主畫面開啟，操作方式就像 App。
② 每日新增紀錄
  1. 進入「記錄」。
  2. 選日期與時間，輸入血壓、心跳、體重、體溫。
  3. 有其他狀況可填在備註。
  4. 按「儲存這筆紀錄」。
③ 修改或刪除

到「歷史」找到該筆資料。按「編輯」可重新修改；按「刪除」會再次要求確認。

④ 產出 PDF
  1. 到「資料」→「產出 PDF」。
  2. Safari 會開啟列印預覽。
  3. 在預覽縮圖上用兩指向外放大，會開啟完整 PDF 預覽。
  4. 再按「分享」，可存到「檔案」／iCloud Drive，或傳給家人、醫師。
⑤ 產出 Excel

到「資料」→「產出 Excel」，系統會建立 .xlsx 檔。iPhone 可儲存到「檔案」或 iCloud Drive，再用 Microsoft Excel、Numbers 等 App 開啟。

⑥ 備份資料
  1. 到「資料」→「備份資料」。
  2. 會產生一個 JSON 備份檔。
  3. 建議存到 iCloud Drive 的固定資料夾。
  4. JSON 包含全部紀錄與備份日期，是未來恢復資料用的主要檔案。
⑦ 恢復備份
  1. 到「資料」→「恢復備份」。
  2. 選擇之前的 JSON 備份檔。
  3. 系統會先顯示資料筆數與日期範圍。
  4. 可選「合併」或「全部取代」。全部取代前，系統會先下載目前資料的安全備份。
⑧ 換新 iPhone
  1. 舊 iPhone 先「備份資料」到 iCloud Drive。
  2. 新 iPhone 用 Safari 開啟同一個 GitHub Pages 網址。
  3. 選「恢復備份」並選取 iCloud Drive 裡的 JSON。
  4. 確認資料後，再加入新 iPhone 主畫面。
⑨ GitHub Pages 部署
  1. 把這個資料夾的所有檔案上傳到 GitHub Repository。
  2. Repository → Settings → Pages。
  3. Source 選「Deploy from a branch」。
  4. Branch 選 main，資料夾選 /(root)，儲存。
  5. 等 GitHub 顯示網址後，用 iPhone Safari 開啟即可。
健康提醒

本工具只做居家紀錄與整理，不能取代醫師診斷。若出現明顯不適或醫師交代的警示情況，請依醫囑處理或就醫。

確認恢復備份

「合併」會保留目前資料並加入備份；「全部取代」會先自動下載目前資料備份，再以匯入檔案取代。
