# 心臟血管手術後居家監測 — iPhone / GitHub Pages 版

這是一個以 iPhone Safari 為主要使用情境的 PWA 網頁工具。

## 功能
- 每日輸入：日期、時間、收縮壓、舒張壓、心跳、體重、體溫、備註
- IndexedDB 本機保存
- 舊版 localStorage 紀錄自動搬移
- 歷史紀錄：編輯、刪除、近 30 / 90 天 / 全部
- 7 / 30 / 90 天血壓與體重趨勢
- 匯出 Excel (.xlsx)
- 產出適合 A4 的 PDF 列印版
- JSON 完整備份
- JSON 恢復：合併或全部取代
- 「全部取代」前自動下載現有資料備份
- PWA：可加入 iPhone 主畫面
- Service Worker：頁面可離線開啟
- 內建 iPhone 使用教學

## GitHub Pages 部署
1. 在 GitHub 建立 Repository。
2. 將本資料夾內的所有檔案與資料夾上傳到 Repository 根目錄。
3. 進入 `Settings` → `Pages`。
4. `Source` 選 `Deploy from a branch`。
5. Branch 選 `main`，Folder 選 `/(root)`，按 Save。
6. 等待 GitHub Pages 建立網址。
7. 用 iPhone Safari 開啟網址。
8. Safari「分享」→「加入主畫面」。

## iPhone 資料備份
網站資料主要儲存在該裝置 / 該網站來源的 IndexedDB。
換手機、清除 Safari 網站資料或改用不同網址前，請先：
1. 「資料」→「備份資料」
2. 將 JSON 存入 iCloud Drive
3. 新裝置打開網站
4. 「資料」→「恢復備份」

## 更新網站時
一般更新 HTML / CSS / JS 不會主動清除 IndexedDB，但仍建議在大型更新前先備份 JSON。

## 隱私
GitHub Pages 只託管程式檔案；本工具不含伺服器端資料庫，健康紀錄不會自動提交到 GitHub。
